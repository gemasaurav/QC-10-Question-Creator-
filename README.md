# ❓ QC:10 — Question Creator

**QC:10** is a fun AI-powered tool that generates **10 high-quality questions** whose answer is any word, name, place, monument, car, number, or concept you provide.

Enter something like:
- `Albert Einstein`
- `Taj Mahal`
- `42`
- `Tesla Model S`
- `Black Hole`
- or literally anything else

…and Grok will invent 10 creative questions that all lead back to that exact answer.

---

## ✨ Features

- Beautiful & simple Streamlit interface
- Powered by **Grok** (xAI)
- Works with any word / phrase / number
- Download the questions as a text file
- Choose between available Grok models
